# YoredTube (יורדטיוב) 🎵🎬

תוכנה שולחנית מקצועית להורדת שירים, סרטונים, פלייליסטים וערוצים שלמים מיוטיוב באיכות מקסימלית.
מותאמת במיוחד לעבודה חלקה תחת כל סוגי סינוני האינטרנט בישראל (נטפרי, אתרוג, אינטרנט רימון, נתיב וללא סינון כלל).

---

## ✨ תכונות מרכזיות
- **הורדת שמע (MP3):** המרה ל-MP3 באיכות גבוהה, כולל הטמעת תמונת שער (Thumbnail) ומטא-דאטה (אמן, שם השיר, אלבום).
- **הורדת וידאו (MP4):** תמיכה באיכויות שונות (1080p, 720p, 480p ואיכות מקסימלית).
- **פורמט נוקיה (AVI):** התאמה ייעודית למכשירי מקשים (Nokia / QWERTY).
- **תמיכה בפלייליסטים וערוצים:** תצוגת רשימה מפורטת עם כפתורי בחירה והורדה מרוכזת.
- **מעקף חסימות ואתגרי יוטיוב:** מנוע QuickJS מובנה לפתרון אתגרי JS ו-n-sig ללא צורך בהתקנת Node.js אצל משתמשי הקצה.
- **זיהוי קישורים מהלוח:** הקפצה אוטומטית כשרץ ברקע ומזהה קישור יוטיוב שהועתק.
- **סרגל התקדמות כולל:** מעקב רציף ואחיד לאורך כל ההורדה.

---

## 🛠️ התקנה והרצה למפתחים

1. התקנת תלויות:
```bash
pip install -r requirements.txt
```

2. הרצת התוכנה:
```bash
python backend.py
```

3. בניית קובץ EXE עצמאי:
```bash
pyinstaller --noconfirm YoredTube.spec
```
